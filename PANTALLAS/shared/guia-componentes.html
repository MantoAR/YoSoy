Listados: YS.tabla

Tabla densa con búsqueda, filtros con contador, orden por columna (con aria-sort), paginación de 25 y estado vacío. Todo en el navegador, sobre las filas que ya trajo la pantalla. Es lo que usan los listados del configurador y Mis pacientes.

YS.tabla(contenedor, {
    filas: turnos, unidad: ["turno", "turnos"], porPagina: 8,
    placeholder: "Buscar paciente…", buscar: t => t.paciente,
    filtros: [
        { id: "todos", texto: "Todos", pasa: () => true },
        { id: "pendientes", texto: "Pendientes", pasa: t => t.estado === "Pendiente" }
    ],
    ordenInicial: { col: 2, desc: true },
    vacio: { icono: "agenda", titulo: "No hay turnos" },
    columnas: [
        { titulo: "Paciente", html: t => YS.esc(t.paciente), orden: t => YS.normalizar(t.paciente) },
        { titulo: "Estado", html: t => YS.turno.chip(t.estado) },
        { titulo: "", clase: "acciones", html: t => `<button class="ui-btn ui-btn--sm">Ver</button>` }
    ]
});   // → { actualizar(filas), estado, buscador }
